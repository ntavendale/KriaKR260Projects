# Linux User Space DMA Repository
This is a copy of the linux kernel driver and user space application source code along with a common header file.
You can find the originals here: [linux-user-space-dma](https://github.com/Xilinx-Wiki-Projects/software-prototypes/tree/master/linux-user-space-dma)

The only difference between the source code in the original repository and this is the comments and annotations I made to help make it easier myself, and anyone else attempting to recreate my sample projects after me, to understand what is going on and what the source code is doing.

Will try to keep the comments in both the user application and here the Pascal port in the [dma-prox-test](https://github.com/ntavendale/KriaKR260Projects/tree/main/KriaAxiDma/dma-proxy-test) folder in sync.
